# Replication pack

Two Paths Out of Imbalance: How Competing Exits Produce Persistence in
Interstate Relations, 1816–2012

Everything needed to reproduce the paper's results, self-contained.

## Contents

```
manuscript/     the manuscript and appendix (PDF + LaTeX source)
scripts/        01-25, run in numeric order (see scripts/README.md)
raw/            Correlates of War source data, as downloaded (unmodified)
data/           intermediate panels the scripts build from raw/ — included
                so you don't have to re-run everything to inspect them,
                but every one of them is fully regenerated by scripts 01-03
results/        every model object, figure, and result table the paper
                cites, as produced by this exact code — use these to check
                your own re-run against the reported numbers
logs/           console output captured from the original run of each script
session_info.txt   R version and package versions used to produce the
                results in results/
```

## How to reproduce

Requirements: R (developed under R 4.6.0; see `session_info.txt`) and the
packages listed there (`dplyr`, `readr`, `tidyr`, `igraph`, `sandwich`,
`lmtest`, `survival`, `purrr`, `readxl`).

```bash
cd replication_pack        # working directory must be this folder
for f in scripts/*.R; do Rscript "$f"; done
```

Or run scripts individually, in numeric order — each one only depends on
outputs from earlier-numbered scripts (all already present in `data/` and
`results/`, so you can also run any single script standalone). All paths
inside the scripts are relative to this folder (`raw/...`, `data/...`,
`results/...`); no path editing is needed, but the working directory must
be `replication_pack/` itself when you invoke `Rscript`.

Running the full pipeline overwrites `data/` and `results/` in place with
freshly regenerated versions. Everything is deterministic except the
agent-based-model scripts (`05_abm_robustness.R`,
`11_abm_threshold_robustness.R`), which set their own random seeds
internally.

## What maps to what in the paper

`scripts/README.md` lists all 25 scripts with a one-line description and
the paper section/table/figure each one feeds. Start there.
